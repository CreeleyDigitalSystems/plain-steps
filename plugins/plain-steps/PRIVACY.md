# Plain Steps privacy

Version 0.1.0 — 3 November 2026

Plain Steps is published by Creeley Digital Systems as skills and example source. It does not operate a hosted AI service or a publisher-run storage service.

## Conversation content

The AI host you choose receives and processes the messages and files you give it under that host's settings, terms and privacy policy. Selecting a skill can place its instructions and relevant supporting material in the model's context. Plain Steps does not add an inbox, publisher connection, analytics service, external endpoint or background message capture.

The package does not itself send conversation content to Creeley Digital Systems. It does not create a separate conversation archive, store diagnostic profiles or require a diagnosis. It does not change the host's own logging, retention, training, memory or deletion controls. Check those controls with the host; the package cannot delete host records.

An assistant may use tools to carry out an authorised task. Those tools and any app the assistant creates have their own data paths. These skills instruct the assistant to respect task boundaries; they are not a technical firewall. Inspect the actual tools, permissions and resulting app before giving sensitive data or authorising external actions.

## Offline packing example

The example is designed to run in the browser without an account, backend, telemetry, external resources or network requests. Item text, packed status and display preferences are kept in that browser's local storage when storage is available. A failed save must be reported rather than described as successful. The browser or operating system may independently keep caches, backups or browsing records.

Local storage has no publisher retention schedule: data remains until the browser/site data is cleared, storage is removed by the browser, or the relevant device/profile is removed. To remove it, use the browser's site-data controls for the example's address. This may also remove other data served from that same origin. Closing the tab alone does not remove local storage. Another person with access to the same browser profile may be able to see the data. Use fictional or non-sensitive items for demonstrations and shared devices.

## Downloads and support

If the package is downloaded from a public repository, that hosting provider processes access according to its own policy. Plain Steps does not add download tracking code. If you post a public issue, its content and your account identity may be public; do not include raw conversations, personal health information, keys or private client data. No support form or automatic support upload is bundled.

## Controls and changes

You can stop selecting the skills or uninstall the plugin using your host's controls. This removes neither previously generated files nor records kept by that host. Review a new version's source and release notes before updating. This document describes this package; it is not a promise about unrelated hosts, integrations or generated apps.

Publication status and the support destination must be verified on the actual release page. This local policy text is not evidence that a policy URL has been published or accepted by a directory.
