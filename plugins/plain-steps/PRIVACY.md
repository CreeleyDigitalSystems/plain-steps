# Plain Steps privacy

Version 0.2.1 — 3 November 2026

Plain Steps is published by Creeley Digital Systems as skills and original local code. It does not operate a hosted AI or publisher-run storage service.

## Conversation content

Your AI host receives the messages and files you provide under its own settings, terms and privacy policy. Relevant skill instructions/resources may enter the model's context. Plain Steps adds no chat capture, inbox, telemetry endpoint, diagnostic profile or transcript archive. It does not itself send conversations to Creeley Digital Systems.

The package does not change the host's logging, retention, training, memory or deletion controls, and cannot delete host records. An assistant may use other authorised tools to complete a task; those tools and the resulting app have their own data paths. These skills do not grant access or provide a technical firewall.

## Local build helpers

The optional calculation scaffolder reads a chosen explicit JSON contract and writes a new local app directory. It refuses an existing destination. The contract is build input authored by the agent, not a profile or intake form for the user. It is not uploaded by the helper.

The optional source inspector reads one selected regular HTML file. It follows no asset links, makes no network requests and executes no page code. Its report is local console output. Neither helper adds automatic report uploads, external analytics or background processing. Local files and command output remain subject to your host, tools, backups and device practices.

## Optional project setup

When requested for a chosen coding project, the setup helper previews a generic instruction block and can create a new standard `AGENTS.md` only after the host confirms the active instruction source. Existing or higher-priority instructions are preserved; merging existing rules uses the host editor under the same project authority. The helper returns metadata and its own block rather than copying surrounding instructions into its report. It changes no global configuration, hooks or credentials, and records no conversations, diagnosis or personal profile. Disabling the plugin does not remove this project file; a requested rollback must preserve any later edits.

## Browser example data

The packing example and generated calculation flow use local browser storage when available. Data includes the app's entered values or items, relevant result/undo state and display preferences. They require no account, server or network request. A save failure is shown; unreadable, unsupported or conflicting stored data is preserved rather than silently reset. Conflict checks are best effort, not atomic coordination between pages.

Storage is unencrypted and tied to the browser/device/origin. Another person using the same browser profile may read it. It can remain until browser/site data is cleared or removed, and can also be evicted by the browser. Moving a local file, private browsing or browser policy can affect access. Closing a tab alone does not remove saved data. The browser or operating system may independently retain caches, backups or browsing records.

To remove example data, use the browser's site-data controls for its address after keeping any information you need elsewhere. That may remove other data from the same origin. Use fictional or non-sensitive values on shared devices; these examples are not backup services or important-record stores.

## Downloads, support and removal

A public source host processes downloads under its own policy. Plain Steps adds no tracking code. Public issue content and your account identity may be visible; do not post raw conversations, health details, credentials or private client data. No support form or automatic support upload is bundled.

You can disable or uninstall the plugin through the host's controls. That does not remove already generated files, example browser data or records held by the host. Review changes before updating. This policy describes this package, not every tool, host or app a model may generate.
