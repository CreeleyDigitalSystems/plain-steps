# Changes

## 0.2.0 — experimental, 3 November 2026

Implemented:

- Ordinary app-build/repair discovery language, with understandable interaction and recovery included in the first flow.
- Focused conversation workflows for rough requests, correction propagation, material ambiguity, faithful rewrites and uncertain incoming messages.
- Original native flow utilities and styles for validation, guarded local state, focus/status/error handling, density and reflow.
- A dependency-free scaffolder for explicit single-result bounded numeric contracts; other tasks keep their actual required operations.
- An optional standard-library HTML source inspector, limited to one file without asset reads or page execution.
- Optional chosen-project defaults, preserving effective existing instructions and refusing unsafe or uncertain file operations.
- Native workshop-loan example with real add/return/history/undo code, and a corrected paint example preserving saved plans and drafts.
- Matched-cue fictional conversation evaluation with blind grading. Both conditions passed; no advantage is claimed.

Code review and native/UI acceptance are separate from this change list. The exact storage fixes and final check results belong in [Verification](docs/VERIFICATION.md). Browser and participant acceptance remain open. Native selection was mixed without project defaults; the configured follow-up read both core skills. No broader automatic-selection guarantee is made.
