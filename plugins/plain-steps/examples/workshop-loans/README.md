# Workshop loan book

An actual native-generated app from an ordinary fictional request. The trace read Plain Steps0.2 build guidance. Open index.html with the sibling files kept together. It starts empty; record an item/borrower, return it, find Returned history and undo the last return. It uses unencrypted browser-local storage, no network/account/server.

Fifteen core logic tests and seven independent logic/simulated-interface probes passed. Real browser editing, keyboard/assistive use, layout and close/reopen remain unverified. This example is not participant validation or proof every generated app works.
